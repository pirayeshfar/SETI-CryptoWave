# 🔐 Security Policy & Responsible Disclosure

## Educational Purpose Statement

**SETI@CryptoWave** is an educational project designed to teach cryptography and digital signal processing concepts to students and enthusiasts. 

This software is **NOT** intended for:
- Covert communications
- Evading law enforcement
- Any illegal activities
- Commercial use without permission

## What This Project Teaches

| Concept | Educational Value |
|---------|------------------|
| AES-256-GCM | Understanding symmetric encryption |
| PBKDF2 | Learning key derivation functions |
| FSK Modulation | Basics of digital signal processing |
| Web Crypto API | Browser-native cryptography |
| Audio Processing | WAV format and signal generation |

## Responsible Use Guidelines

### ✅ Appropriate Uses
- Learning cryptography concepts
- Academic research and education
- Personal experimentation
- Teaching demonstrations
- Science fair projects

### ❌ Inappropriate Uses
- Any illegal communications
- Evading detection or monitoring
- Commercial products without license
- Any activity that violates local laws

## For Educators

If you're using this project in a classroom:

1. **Discuss ethics**: Talk about responsible use of cryptography
2. **Explain legal context**: Cryptography laws vary by country
3. **Focus on learning**: Emphasize the educational concepts
4. **Encourage creativity**: Inspire students to build, not break

## Reporting Security Issues

If you discover a security vulnerability:

1. **Do NOT** create a public issue
2. Contact the author privately
3. Allow reasonable time for a fix
4. Do not exploit the vulnerability
